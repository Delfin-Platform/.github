# DelfiN GitHub identity

Public organization profile and original GitHub branding assets. The profile appears on [DelfiN on GitHub](https://github.com/Delfin-Platform).

- `profile/README.md` — public organization introduction.
- `profile/header.png` — 1600 × 560 README cover.
- `profile/avatar.png` — 256 × 256 compact identity, prepared from the original DelfiN symbol.

Based on the DelfiN design language: Primary `#123272`, Inter, IBM Plex Mono, left alignment, square geometry and fine rules. Original logo proportions are preserved. Artwork is DelfiN project branding; publication does not grant a blanket third-party reuse license.
